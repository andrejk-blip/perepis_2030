# Чек-лист релиза через GitHub

## Первый релиз v14.0

```bash
git init
git add .
git commit -m "Release v14.0"
git branch -M main
git remote add origin <АДРЕС_ВАШЕГО_РЕПОЗИТОРИЯ>
git push -u origin main
git tag -a v14.0 -m "Protected public release v14.0"
git push origin v14.0
```

После push включите GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root)**.

## Следующие версии

1. Рабочую версию меняйте отдельно.
2. Перед публикацией копируйте проверенный релиз в `index.html`.
3. Обновляйте `VERSION`, `CHANGELOG.md`, build-маркер и `SHA256SUMS.txt`.
4. Делайте отдельный commit и тег (`v14.1`, `v14.2` и т. д.).
5. Не переписывайте старые теги: они должны оставаться неизменяемой историей релизов.

## Минимальная проверка перед push

- открывается стартовый экран;
- новая игра запускается;
- пауза → «Сохранить и выйти» возвращает в меню;
- «Продолжить» восстанавливает прогресс;
- «Знаете ли вы?» не ломает игру и «Узнать больше» открывает факты;
- справка → «Об игре» показывает v14.0;
- таблица рекордов открывается;
- в браузерной консоли нет новых JavaScript-ошибок.
