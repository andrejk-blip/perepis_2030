# Перепись: Большая экспедиция — v14.9

Итоговая публикационная сборка браузерной игры. Главный файл — `index.html`. Внешний Node.js-сервер для GitHub Pages не нужен; сетевые функции игры используют Supabase.

## Что входит

- `index.html` — итоговая игра v14.9.
- `SUPABASE_SETUP_FINAL.md` — пошаговая настройка базы, рейтинга и обратной связи.
- `00_SUPABASE_PRECHECK.sql` — безопасная диагностика перед изменениями.
- `01_SUPABASE_FINAL_MIGRATION.sql` — настройка обратной связи и условное исправление RLS для рейтинга.
- `02_SUPABASE_VERIFY.sql` — проверка после миграции.
- `RELEASE_CHECKLIST.md` — короткий сценарий публикации и контрольного теста.
- `FINAL_QA.md` — результаты финального smoke-теста сборки.
- `RIGHTS.md`, `LICENSE` — сведения об авторстве и режиме использования.
- `SHA256SUMS.txt` — контрольные суммы релиза.

## Совместимость

Публичный номер сборки — **v14.9**, build — `PBE-AK-2026-v14.9`. Внутренний идентификатор игрового зачёта и формат локальных сохранений намеренно не менялись, поэтому существующие сохранения и общий зачёт коллег не должны разделяться из-за номера публикационной версии.

## Публикация

Для существующего репозитория `andrejk-blip/perepis_2030` загрузите содержимое этого каталога в корень ветки `main`, заменив старые одноимённые файлы. GitHub Pages продолжит использовать корневой `index.html`. Перед публикацией сначала выполните шаги из `SUPABASE_SETUP_FINAL.md`.
