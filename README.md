# Перепись: Большая экспедиция — v14.0

Публичная защищённая сборка браузерной игры. **v14.0 — базовая точка дальнейшей нумерации защищённой ветки.**

## Что публиковать

Для GitHub Pages достаточно содержимого этого каталога. Главная страница уже называется `index.html`; внешняя сборка и сервер Node.js не нужны.

## Быстрая публикация через GitHub Pages

1. Создайте новый репозиторий на GitHub. Если исходник не хотите показывать шире необходимого, публикуйте в него только файлы из этого релизного каталога.
2. Загрузите файлы в корень репозитория и сделайте commit, например `Release v14.0`.
3. Поставьте Git-тег `v14.0` на этот commit.
4. В GitHub откройте **Settings → Pages** и выберите публикацию из основной ветки (`main`), каталог `/ (root)`.
5. После появления адреса Pages откройте игру, начните новую экспедицию, сделайте одну анкету, обновите страницу и проверьте продолжение сохранения. Затем проверьте таблицу рекордов.

## Важно про сервер результатов

В `index.html` используется **publishable** ключ Supabase. Такой ключ по назначению находится на клиенте и будет виден в браузере и публичном репозитории. Никогда не помещайте сюда `service_role`, secret key или иной серверный секрет. Безопасность базы должна обеспечиваться настройками RLS/RPC на стороне Supabase.
