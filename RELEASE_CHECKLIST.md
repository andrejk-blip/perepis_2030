# Чек-лист публикации v14.9

## До GitHub

1. Выполнить `00_SUPABASE_PRECHECK.sql`.
2. Выполнить `01_SUPABASE_FINAL_MIGRATION.sql`.
3. Выполнить `02_SUPABASE_VERIFY.sql`.
4. Проверить один тестовый feedback в Supabase Dashboard.
5. По возможности проверить общий рейтинг двумя браузерами.

## Публикация

1. Открыть репозиторий `andrejk-blip/perepis_2030`.
2. Заменить корневой `index.html` файлом из этого пакета.
3. Заменить `README.md`, `CHANGELOG.md`, `RIGHTS.md`, `VERSION`, `SHA256SUMS.txt`; добавить SQL и инструкции из пакета.
4. Commit: `Release v14.9 — final publication build`.
5. При желании поставить Git tag `v14.9`.
6. GitHub Pages оставлять: branch `main`, folder `/ (root)`.

## После публикации

Открыть Pages в обычном и приватном окне и проверить: старт игры, звук, переход по регионам, одну ситуацию и анкету, сохранение/продолжение, библиотеку, общий рейтинг, форму «Сообщить».

Если всё зелёное — эту версию фиксировать как публикационную базу, а дальнейшие функциональные изменения вести уже следующей версией.
